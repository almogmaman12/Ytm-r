One switch to turn on in Chrome Open Chrome's extension page, press Details on YT Music Remote, and turn on Allow User Scripts. (Older Chrome versions: turn on Developer mode at the top right instead.) Then come back here.
The new version is saved. Reload the YouTube Music tab once to start it.
Your relay has a newer version that needs a newer extension. Replace the extension folder with the latest one from your repository and reload it in chrome://extensions.

What this runs

This extension downloads its code from the relay address above and runs it only on music.youtube.com. Use a relay you control, and keep two-step verification on the accounts that can change it (your git host and your server host), because whoever can change those files can change what runs here.
